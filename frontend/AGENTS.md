# 前端修改约定

- 2026-10-09 用户确认“布局设计就暂定这样”：当前布局和 Soft/indigo 风格作为已确认的暂定基线。后续工作沿用，只有用户明确要求时才调整布局或风格。对照截图为 `examples/preview_restored_style.png`。

- 用户要求每次修改前留备份。修改前在本目录执行 `python backup_frontend.py --label before-change`，保留现有截图；备份不可覆盖。
- 用户只要求布局时，只调整布局，不自行更换主题、配色、字体、按钮或已有控件设计。
- 当前使用 Gradio Soft/indigo 原视觉。用户明确否定过 teal/slate 主题重做，不再恢复该方案。
- 保留轮询不变淡、不闪烁和未变化视图使用 gr.skip() 的修复；不能为视觉回滚撤掉这些修复。
- 用户于 2026-10-09 明确要求执行动态加入局部动画：处理/排队显示旋转圆圈与扫光，待人工确认显示较慢扫光。保留完成/错误/暂停状态静止；这是状态提示动画，不改变模拟标记或宣称模型思考。不能扩展为整个面板反复变淡。
- 阶段方块详情只悬停显示，移开收起；不恢复点击锁定展开。执行记录可点击查看依据。
- 审阅等待不使结果失效；未生成的步骤保持 pending。相同源文保存不增加版本、不使结果失效。保存保持当前审阅位置，仅 resume 后执行后续起点。stale 对应“旧结果待更新”，不能当作时间过期。
- 必须遵守项目根 AGENTS.md 的阶段与本机/服务器边界。
- 2026-10-09 用户明确要求逐步审核，取代早期合并检查点：OCR 开放源文，emotion 开放情绪，light_tts（翻译与轻量试听完成）开放译文/候选，routing 单独开放路由依据，tts 开放试听/返工。每次只有一个当前板块，未来隐藏、已确认内容折叠只读。TTS 可明确返回翻译或情绪。新检查点自动载入当前句，同一检查点轮询不覆盖草稿；未保存草稿与 revision 冲突禁止确认。
- 用户授权的 v0.2 模拟补充：人工情绪保留原识别；TTS 独立试合成与明确采用分开，试合成不覆盖原正式结果。采用才替换本句并使成品待更新；过期/失败试合成禁止采用。路由理由来自后端字段与真实命中条件，不以原声时长或附图 RTF 冒充实测规则。
- 任务 completed 后当前工作台只读：配音区收起并作为结果查看，隐藏重做/返回翻译/试合成/采用等处理控件，不再标“当前步骤”。旧标签页操作也须检查最新服务状态并返回 JOB_COMPLETED，不能只靠按钮禁用。待确认与部分失败仍可按阶段修复；不新增重开任务入口。
- GitHub frontend 分支交付放在仓库根 frontend/ 与 docs/stage10/；不移动原后端。mock 可读本阶段冻结 source 或仓库根现有 scheme3_policy.py，必须校验已核对 SHA-256（只容许 LF/CRLF 转换）；不写入源码目录。上传包用 allowlist 排除环境、DB、缓存、备份和实验媒体，不擅自推送远端。
